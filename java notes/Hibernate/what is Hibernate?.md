Hibernate is an **ORM (Object-Relational Mapping) framework** for Java that maps Java objects to database tables.

## Why Hibernate?

- Reduces manual JDBC code.
    
- Maps Java classes to database tables.
    
- Performs CRUD operations using Java objects.
    
- Supports multiple databases through configuration.
    

## How It Works

```
Java Object
     |
     v
  Hibernate
     |
     v
   Database
  (SQL Tables)
```

## Important Terms

- **ORM:** Maps Java objects to relational database tables.
    
- **Entity:** Java class mapped to a database table.
    
- **Hibernate vs JDBC:** JDBC requires more manual SQL and result handling; Hibernate provides object-relational mapping and manages much of that work.
    

## Interview Point

Hibernate is an ORM framework that simplifies database operations by mapping Java objects to database tables.

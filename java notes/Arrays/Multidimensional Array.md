
A multidimensional array is an array containing other arrays.

The most common one is a 2D array, which looks like rows and columns.

### Example

```
int[][] nums = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

Think of it as a table:

```
        column
        0  1  2
      ┌─────────
row 0 │ 1  2  3
row 1 │ 4  5  6
row 2 │ 7  8  9
```

### Why use a 2D array?

When data naturally has **rows and columns**.

Examples:

- Marks of students across subjects
- Matrix
- Chess board
- Seating arrangement
- Game board

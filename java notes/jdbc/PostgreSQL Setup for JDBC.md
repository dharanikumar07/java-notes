## Requirements

- Install PostgreSQL.
    
- Create a database.
    
- Know the database username, password and port.
    
- Add the PostgreSQL JDBC driver to the project.
    

## Default Port

`5432`

## JDBC URL

```
jdbc:postgresql://localhost:5432/mydb
```

- `localhost` → Database server location.
    
- `5432` → PostgreSQL port.
    
- `mydb` → Database name.
    

## Important

The JDBC driver allows Java to communicate with PostgreSQL.

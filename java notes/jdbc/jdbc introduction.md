## Definition

JDBC (Java Database Connectivity) is a Java API used to connect Java applications to databases and execute SQL queries.

## Why JDBC?

- Connect Java with a database.
    
- Execute SQL statements.
    
- Insert, update, delete and retrieve records.
    

## Main JDBC Components

- `Connection` → Connects to the database.
    
- `Statement` → Executes SQL queries.
    
- `PreparedStatement` → Executes parameterized SQL queries.
    
- `ResultSet` → Holds retrieved query results.
    

## Flow

Java → JDBC Driver → Database

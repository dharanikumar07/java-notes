## Definition

The PostgreSQL JDBC driver is a library that enables Java applications to communicate with PostgreSQL.

## Maven Dependency

```
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <version>42.7.8</version>
</dependency>
```

## Without Maven

Add the PostgreSQL JDBC JAR to the project's classpath.

## Remember

Maven downloads and manages the driver dependency automatically.

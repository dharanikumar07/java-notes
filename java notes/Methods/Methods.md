## 1. What is a Method?

A **method** is a block of code that performs a specific task.

Instead of writing the same code repeatedly, we define it once inside a method and **call it whenever needed**.

### Example

```
class Calculator {

    int add(int a, int b) {
        return a + b;
    }
}
```

Here:

```
add() → method
a, b  → parameters
a + b → logic
return → sends result back
```

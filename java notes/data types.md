
Data type → Defines what type of value a variable can store.

Java has 2 main types:

### 1. Primitive
8 built-in basic types:

- byte   → small integer
- short  → integer
- int    → integer
- long   → large integer
- float  → decimal
- double → decimal
- char   → single character
- boolean → true/false

### 2. Non-Primitive (Reference)
Used for objects/references.

Examples:
- String
- Array
- Class
- Object
- Interface
- Enum

Easy memory:
Primitive = 8 basic types
	Non-Primitive = Objects/References
